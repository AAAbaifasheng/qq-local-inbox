# QQ Local Inbox 使用教程与注意事项

> 适用版本：2026-10 当前 `main` 分支。界面文字以程序实际显示为准。
>
> 本项目不是腾讯 QQ 官方产品，也不隶属于 NapCatQQ。QQ 接入、NapCat 使用和第三方模型服务均需遵守各自条款。

## 1. 它解决什么问题

QQ Local Inbox 把 QQ 消息和（可选）学习通作业整理到桌面面板：

- 作业、实验报告、课程通知
- 学习通课程作业、截止时间与提交状态（可选只读桥）
- 比赛、竞赛、报名、提交截止
- 项目、开发、评审
- 邀约、见面、待回复
- 行政材料、缴费、出行、就医

程序只做“分拣”和“提示”，不会自动回复、不会替你答应邀约，也不会自动把候选加入待办。每条候选都需要你确认或忽略。

## 2. 前置条件

- Windows 10/11 x64
- Python 3.11 或 3.12，安装时需要包含 Tcl/Tk
- 已安装并登录 NapCatQQ，且 QQ 本身工作正常
- 能够访问 `127.0.0.1` 的本机端口
- 如需远程模型：可访问对应 HTTPS 服务，并准备 API Key
- 如需学习通作业：浏览器安装 Tampermonkey/Violentmonkey，并已登录学习通

程序不提供 QQ 登录能力。请先完成 QQ 登录和 NapCat 登录，再启动本程序。

## 3. 安装与启动

1. 下载或解压项目目录。
2. 在项目目录打开 PowerShell。
3. 执行：

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1
   ```

4. 双击 `run.bat` 启动。
5. 如果 NapCat 尚未运行，先按 [NapCat 配置](NAPCAT_SETUP.md) 完成 WebSocket/HTTP 设置。

安装脚本只创建 `.venv` 并安装 `websocket-client`，不会修改系统 Python，也不会写入 API Key。

### 可选：创建桌面快捷方式

在项目目录执行：

```powershell
$root = (Get-Location).Path
$shell = New-Object -ComObject WScript.Shell
$shortcut = $shell.CreateShortcut((Join-Path $env:USERPROFILE 'Desktop\QQ Local Inbox.lnk'))
$shortcut.TargetPath = Join-Path $root '.venv\Scripts\pythonw.exe'
$shortcut.Arguments = 'launcher.py'
$shortcut.WorkingDirectory = $root
$shortcut.IconLocation = Join-Path $root 'assets\icon.ico'
$shortcut.Save()
```

## 4. NapCat 配置

最小配置：

- OneBot 11 WebSocket Server：`ws://127.0.0.1:3001`
- 如需要“同步今天”或“导入历史”，再开启 HTTP Server：`http://127.0.0.1:3000`
- 两个服务都只绑定回环地址，不要绑定 `0.0.0.0`
- 建议设置独立的 Access Token；本机单人使用可以留空，但共享电脑不要留空

完整步骤见 [docs/NAPCAT_SETUP.md](NAPCAT_SETUP.md)。

## 5. 首次配置

启动后点击右上角“设置”，右侧会滑出设置抽屉：

1. 在“连接”页确认 NapCat WebSocket 地址。
2. 填写 Access Token，可留空。
3. 在“模型”页选择分析方式：
   - **本地规则**：不调用模型，速度最快，不发送聊天文本。建议先使用此模式。
   - **大模型 API（本机/远程）**：调用 OpenAI 兼容接口。
4. 如使用模型：
   - 本机 Ollama：Endpoint 选 `Ollama`，点击“拉取模型”，选择例如 `qwen3:8b`。
   - 本机 LM Studio：Endpoint 选 `LM Studio`，点击“拉取模型”读取模型标识。
   - DeepSeek：Endpoint 选 `DeepSeek`，模型使用 `deepseek-flash`，填写 API Key，并勾选远程知情确认。
5. 选择是否“接收群消息”。开启后实时群聊与今日同步使用同一范围。
6. 选择是否“启动时自动连接”和“启动时同步今天消息”。
7. 点击抽屉底部“保存并连接”，或关闭抽屉后点击右上角“开始监听”。

API Key 和 Token 使用 Windows DPAPI 加密保存在本机，不需要每次输入。远程知情确认保存在 `settings.json`，但不会保存明文 Key。保存后 API Key 输入框会清空，不会回显；留空表示保持原 Key。

## 6. 日常使用

### 6.0 一键启动与扫码登录

1. 打开“设置 → 连接”，在“NapCat 安装目录”填 NapCat 文件夹（含 `NapCatWinBootMain.exe`），点“检测”可自动查找。
2. 点“读取 WebUI Token”，程序会从本机 NapCat 配置读取并 DPAPI 加密保存；也可以手动填写。
3. 保持“启动时自动拉起 NapCat”开启。之后启动 Inbox 会隐藏启动 NapCat：
   - 有已保存账号且开启“免扫码快速登录”时，直接登录；
   - 否则弹出登录窗口，显示二维码。用手机 QQ 扫码，并在手机上确认。
4. 登录成功后自动连接 WebSocket、同步今天消息；窗口关闭。
5. 如果二维码过期，点“刷新二维码”；如果 NapCat 没启动，点“重试”或“打开 NapCat 控制台”。

注意：程序不会代替你扫码，也不保存 QQ 账号密码；二维码只在本机窗口显示，不要截图分享。

### 6.1 事务中心

顶部五张卡片：

- **今日待办**：已确认且截止日期为今天的待办
- **待回复**：需要你回应的活跃事项
- **比赛与项目**：进行中的比赛、项目事项
- **待确认邀约**：尚未确认的见面邀约
- **课程作业**：学习通中待做/未交的课程作业（需先接入学习通）

“优先处理”列表按优先级显示待确认和已确认事项。单击一行后，上方蓝色条会显示当前选中的优先级、联系人、事项和截止时间；选中状态会用蓝底蓝字标出。选中后可：

- 查看完整信息（完整原始文字、来源、时间、分析理由、截止；窗口内可直接确认/忽略/完成，也可复制全文）
- 确认加入待办
- 忽略此候选
- 标记完成

待确认事项不会自动进入待办。所有列表（待审核、已确认待办、比赛/竞赛、课程作业、最近消息、联系人排序）都支持“查看完整信息”，双击行也可以打开。

### 6.2 页面

- **比赛/竞赛**：集中展示所有比赛、竞赛相关候选与待办，可按状态查看详情、确认、忽略或完成。
- **课程作业**：从学习通只读同步的作业列表；可打开作业页、查看详情、确认加入待办、忽略或标记完成。作业默认是“待确认”。
- **最近消息**：本机收到的文本消息；群聊和私聊都只保存文本，不下载图片、文件、语音。
- **待审核事务**：所有等待人工确认的候选。
- **已确认待办**：你确认过的事项。
- **联系人排序**：按待处理工作量、回复需求和最近消息排序，不是对联系人个人价值的评价。

### 6.3 同步今天

点击“同步今天”会通过本机 NapCat HTTP 接口读取最近 50 个会话中今天有活动的文本：

- 每会话最多 30 条
- 总计最多 300 条
- 已入库的消息直接跳过
- 群聊需先开启“接收群消息”
- 规则模式只做本地分析；API 模式先用本地规则预筛，只有候选/待回复文本才调用模型

同步失败时会显示首个失败原因；单条失败不会中断整次同步。

### 6.4 导入历史

打开“设置 → 数据”，点击“导入历史消息”：

1. 填写本机 NapCat HTTP 地址和 HTTP Token。
2. 选择好友或群。
3. 设置导入条数，最多 200 条。
4. 点击“开始导入”。

导入使用当前分析模式。远程 API 模式下，导入的每条文本都会发送给服务商；对话框中会再次提示。

### 6.5 隐私说明

点击底部“隐私说明”查看当前数据路径、凭据保存方式、远程外发范围、更新检查和清除方式。

### 6.6 接入学习通作业

1. 打开“课程作业”页，点击“接入说明”。
2. 按对话框提示复制油猴脚本，粘贴到 Tampermonkey/Violentmonkey 并保存。
3. 在学习通课程作业页使用右下角面板“同步当前页”；在“我学的课”页面可尝试“全部课程”。
4. 同步后的作业默认待确认；选中后可“打开作业页”“确认加入待办”“忽略”或“标记完成”。

只读取课程名、作业标题、截止时间、平台状态和链接；不保存学习通账号密码或 Cookie，不下载附件，不自动提交。学习通没有公开官方 API，页面改版后脚本可能需要更新。详细步骤、数据边界和故障排查见 [学习通作业接入](CHAOXING_SETUP.md)。

### 6.7 设置抽屉与自动更新

设置抽屉分四页：

- **连接**：WebSocket 地址、Access Token、群消息、自动连接、自动同步。
- **模型**：本地规则 / 大模型 API、预设、Endpoint、模型、API Key、远程知情确认、测试连接。
- **更新**：当前版本、自动检查 / 下载 / 应用开关、手动检查、立即重启并更新。
- **数据**：数据目录、导入历史、清除凭据、清空本地数据、隐私说明。

自动更新规则：

- 启动时检查 GitHub Releases；发现小版本更新后自动下载并校验 SHA256，下次启动时应用。
- 更新前备份运行文件，失败会尝试回滚；不会在分析或同步过程中替换文件。
- 大版本更新只提示，需要手动确认。
- 开发目录（存在 `.git`）默认不自动覆盖；如需测试，可设置 `QQLI_FORCE_UPDATE=1`。
- 更新检查只访问 GitHub，不上传聊天记录、Token 或 API Key。

如果自动更新失败：打开“设置 → 更新”查看错误；也可以从 GitHub Releases 手动下载最新 zip，解压覆盖程序目录（保留 `%LOCALAPPDATA%\QQLocalInbox\` 数据目录）。

## 7. 分拣规则

分类包括：作业/课程、比赛/竞赛、项目/开发、邀约/见面、求助/待回复、行政/材料、财务/缴费、出行/行程、健康/就医、普通消息。

优先级：

| 优先级 | 含义 |
| --- | --- |
| P0 | 非常紧急或分数很高，优先处理 |
| P1 | 重要，通常涉及近期截止或明确行动 |
| P2 | 需要处理，但时间压力较小 |
| P3 | 低优先级或仅作提示 |

群聊降噪规则：

- 只有直接 @ 你、群主/管理员或群公告要求全体成员执行、带明确截止时间的作业/报名/提交通知、比赛/竞赛公开信息才生成候选。
- 群内普通提问、讨论、玩笑、招募/代课/家教广告只本地入库，不生成待办。
- 同一会话、同一文本、同一截止日的活跃待办会自动合并。
- 私聊消息按“是否需要你处理/回复”判断。

时间规则：

- 日期按消息发送时间推算，不按程序启动时间。
- “今天/今晚/明天/后天/周末/周X/下周X/明确日期”等会转成具体日期。
- 相对标签会按当前日期重新显示，例如昨天创建的“明天”事项今天会显示“今天”。
- 模型给出的明确日期优先于消息中含糊的“今天”字样。
- 无法确定时显示“待核对”，不会猜测。

## 8. 数据与凭据

默认数据目录：

```text
%LOCALAPPDATA%\QQLocalInbox\
```

包含：

- `inbox.sqlite3`：消息、待办与课程作业
- `settings.json`：端点、模型、开关与学习通接收端口，不含 Key/Token
- `secrets.dat`：DPAPI 加密的 API Key / NapCat Token / 学习通接入令牌
- `updates/`：下载中的更新包、已暂存版本和 `v旧版本` 备份；可在确认不需要回滚后手动删除

“设置 → 数据”中的操作：

- **清除已保存凭据**：删除 Key/Token，重置学习通接入令牌，并取消远程知情确认；不删除消息和待办。学习通脚本需要重新复制。
- **清空本地数据…**：删除消息、待办与课程作业，无法撤销。

数据库本身没有字段级加密。请使用 Windows 设备加密 / BitLocker，不要将数据库同步到未经审查的网盘。

## 9. 注意事项

1. **账号与条款**：QQ 接入、NapCat 使用需遵守腾讯 QQ 用户协议、NapCat 上游许可和当地法律。使用第三方协议端可能存在账号风险，请自行评估。
2. **不要公开端口**：NapCat WebSocket/HTTP 只绑定 `127.0.0.1`，不要做端口映射，不要把服务暴露到公网。
3. **Token 和 Key**：不要把 Access Token、API Key 写进截图、聊天、代码、Issue 或提交历史。若已暴露，立即在服务商/NapCat 中轮换。
4. **远程 API 外发**：勾选远程 API 后，消息文本和最少上下文（私聊/群聊、是否 @ 你、发送者角色）会发送给服务商；不发送群名称、图片、文件或语音。请阅读服务商隐私政策。
5. **费用**：远程 API 按 Token 计费；群聊预筛和规则模式可以显著减少调用。详见 [API 与费用](API_AND_MODELS.md)。
6. **模型会出错**：分类、标题、日期和优先级都可能误判。所有候选必须人工确认；不要用程序替代重要事务的最终核对。
7. **时间歧义**：一条长消息可能同时出现多个日期。程序会优先采用明确的截止日期，但仍可能把“今天”误认为截止日；请以原文为准。
8. **群聊隐私**：开启群消息后，群内闲聊也会本地入库。若不需要群聊，关闭“接收群消息”即可。
9. **媒体不分析**：程序只处理文本，图片、文件、语音、表情不会下载或分析。
10. **不会自动操作 QQ**：程序不发送消息、不自动回复、不自动接受邀约、不自动登录 QQ。
11. **NapCat 版本变化**：NapCat/QQ 更新后，接口、字段或登录方式可能变化；遇到问题先查看 NapCat 官方文档和日志。
12. **安全删除限制**：清空数据会执行 SQLite `secure_delete`、WAL 截断和 `VACUUM`，但无法覆盖 SSD 磨损均衡、快照、备份或云同步副本。
13. **DPAPI 与 Windows 账户**：`secrets.dat` 只能由当前 Windows 用户解密；更换账户或迁移电脑后需要重新输入 Key/Token，并重新复制学习通脚本。
14. **公共电脑**：不要在共用 Windows 账户上保存凭据；使用独立账户、锁屏密码和 BitLocker。
15. **学习通条款**：学习通没有面向学生的公开官方 API；只读同步依赖网页结构，可能受平台用户协议限制。使用前请自行确认学校与平台规定，并自行评估账号风险。
16. **学习通页面变化**：学习通改版后，作业识别可能失效；用面板“预览识别结果”排查，必要时更新 `assets/chaoxing_bridge.user.js`。
17. **学习通接收端口**：本机接收服务只监听 `127.0.0.1`，请求必须带脚本中的随机令牌。不要把脚本或令牌发给别人；如果端口被占用，程序会自动换端口，需要重新复制脚本。

## 10. 常见问题

**连接失败**：确认 NapCat 已登录、WebSocket Server 已开启、地址和 Token 正确。不要填 NapCat WebUI 密码。

**收不到群消息**：在“连接设置”中勾选“接收群消息”，并确认 NapCat 的事件范围。

**同步今天为 0 条**：可能今天没有新文本、消息已入库，或 HTTP Server 未开启。

**API 报 401/403**：检查 API Key、余额、模型名和远程知情确认。DeepSeek 当前模型名为 `deepseek-flash` 或 `deepseek-v4-pro`。

**本地模型返回格式错误**：程序会尝试去除 Markdown JSON 代码块并提取 JSON；如果仍失败，换用指令模型、开启 JSON 模式，或先用规则模式。详见 [API 与本地模型](API_AND_MODELS.md)。

**本地模型很慢**：7B/8B 模型在 GPU 上通常比 14B/32B 快；CPU 运行会明显变慢。高消息量建议规则模式或更小模型。

**费用比预期高**：检查是否使用 Pro 模型、是否开启思考模式、是否在高峰时段调用、是否把大量群聊送给了远程模型。程序默认对 DeepSeek 关闭思考模式，并对群聊做本地预筛。

**应用启动失败**：确认 `.venv\Scripts\python.exe` 存在、Python 包含 Tcl/Tk、没有其他实例占用数据库；必要时在 PowerShell 中运行 `run.bat` 查看错误。

**学习通页面没有同步面板**：确认 Tampermonkey/Violentmonkey 已启用脚本、当前是 `chaoxing.com` 页面并已刷新；部分页面使用 iframe，可直接打开课程作业列表再试。

**学习通提示“没有识别到作业”**：先点“预览识别结果”；如果为 0，说明当前页不是作业列表或页面结构未识别。尝试进入具体课程的作业页，或等待脚本适配新页面。

**学习通提示“无法连接本机程序”**：确认程序正在运行，并在“接入说明”中核对接收服务已启动和实际端口；重启后端口变化时需要重新复制脚本。

**学习通提示“访问令牌无效”**：脚本是旧令牌版本；打开“接入说明”重新复制并粘贴最新脚本。
